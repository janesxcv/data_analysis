# Лабораторная работа № 3. Статистический анализ продаж с помощью NumPy

**Тема:** Aggregation-axis  
**Единицы измерения:** тыс. денежных единиц.  
**Период:** 8 недель. Строки массива — регионы, столбцы — недели.

## Код решения

```python
import numpy as np

sales = np.array([
    [120, 125, 130, 128, 135, 140, 138, 145],
    [ 80,  82,  79,  85,  88,  90,  86,  92],
    [150, 148, 155, 160, 158, 165, 220, 170],
    [ 60,  65,  62,  58,  64,  63,  61,  66],
    [100, 105, 102, 108, 110, 112, 109, 115],
], dtype=float)
region_names = np.array(["Bishkek", "Osh", "Karakol", "Tokmok", "Jalal-Abad"])

# Проверка формы и исходных данных
assert sales.shape == (region_names.size, 8)
assert np.all(np.isfinite(sales)) and np.all(sales >= 0)

# Задания 1–2: ось 1 объединяет недели внутри каждого региона
total = np.sum(sales, axis=1)
weekly_mean = np.mean(sales, axis=1)
weekly_median = np.median(sales, axis=1)
std = np.std(sales, axis=1, ddof=0)
q1 = np.percentile(sales, 25, axis=1)
q3 = np.percentile(sales, 75, axis=1)
iqr = q3 - q1
cv = std / weekly_mean * 100  # коэффициент вариации, %

# Задание 3: границы Тьюки и маска выбросов
lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr
outlier_mask = (sales < lower[:, None]) | (sales > upper[:, None])
# np.where возвращает индексы строк и столбцов без ручного обхода
outlier_region_idx, outlier_week_idx = np.where(outlier_mask)
outlier_values = sales[outlier_region_idx, outlier_week_idx]

# Задание 4: доля выручки; знаменатель проверяется до деления
store_total = np.sum(total)
assert store_total > 0
share = total / store_total * 100

# Задание 5: средние за первые и последние четыре недели
first_mean = np.mean(sales[:, :4], axis=1)
last_mean = np.mean(sales[:, 4:], axis=1)
change_abs = last_mean - first_mean
change_pct = np.divide(
    change_abs, first_mean,
    out=np.full_like(change_abs, np.nan), where=first_mean != 0
) * 100

# Задание 6: исключаем только помеченные значения; nan позволяет
# агрегировать строки разной длины без циклов и изменения исходного массива
sales_without_outliers = np.where(outlier_mask, np.nan, sales)
clean_total = np.nansum(sales_without_outliers, axis=1)
clean_mean = np.nanmean(sales_without_outliers, axis=1)

# Контрольные проверки
assert np.isclose(total.sum(), sales.sum())
assert np.isclose(share.sum(), 100)
assert outlier_mask.sum() == 1
assert np.isclose(clean_total.sum(), sales.sum() - outlier_values.sum())
assert np.all(change_abs > 0)
```

## 7. Критерий проблемного региона

Для первичного сигнала предлагается считать регион требующим внимания, если одновременно выполняются два условия:

1. коэффициент вариации превышает 10% (заметные колебания относительно типичного масштаба региона);
2. доля в выручке превышает 20% (изменения в регионе способны заметно повлиять на общий результат магазина).

Порог 10% — рабочий аналитический порог для этой учебной выборки, а не универсальный норматив. По этому правилу внимание требуется **Karakol**: CV = 13,03%, доля = 29,94%. Сигнал усиливает найденное отклонение 220 тыс.; при этом вторая половина периода в регионе выросла, поэтому вывод — проверить причину всплеска и устойчивость роста, а не автоматически считать регион убыточным или проблемным. Остальные регионы не проходят оба условия одновременно. Низкая абсолютная выручка Tokmok сама по себе не является основанием для такого вывода: данных о размере рынка и затратах нет.

Поскольку все регионы показывают положительную динамику, текущая картина в целом благоприятна, но период всего восемь недель и данных недостаточно для сезонных выводов.

Размер рынка и численность клиентской базы позволят сравнивать регионы по проникновению и потенциалу, а не только по абсолютной выручке.
